The Problem Statement

Multi-modal, Sun angle and scale invariant image correspondence using Chandrayaan-2 optical images (OHRC, TMC and IIRS).

Background

Image Registration is the process of aligning two or more images of the same scene taken at different times, from different viewpoints, or by different sensors into a common coordinate system.

  • Source Image (Moving): The image geometrically transformed to align with the reference image.
  • Reference Image (Fixed): The target image about which the source image is aligned.

Expected Solution

A generic software solution for finding correspondence between Chandrayaan-2 optical images and lunar reference images with sub-pixel accuracy, maintaining a uniform distribution of match points across the image.

Deliverables: - Software + registered product with corresponding match points.
- Evaluation metrics (RMSE, inlier match count, inlier ratio, etc.)

Key Challenges

Illumination Variation

Changes in sun azimuth and elevation alter surface lighting and feature appearance (e.g., crater shadows), making standard correlation highly difficult.

Viewpoint Variation

Geometric distortions arise from different camera positions and orientations. Features appear shifted, scaled, rotated, or perspective-distorted.

Scale Variation

Different missions operate at varying orbital altitudes and sensor resolutions (OHRC vs TMC vs IIRS), creating large scale ratios between source and reference images.

Our Approach

A robust, 6-step computational pipeline designed to overcome lunar topography constraints and achieve sub-pixel geometric alignment.

Step 01

Preprocessing & Normalization

Contrast enhancement and noise filtering using advanced CLAHE and bilateral filtering to normalize drastically different sensor histograms.

Step 02

Feature Detection & Description

Multi-modal, illumination-invariant feature extraction (e.g., modified SIFT/SuperPoint) adapted specifically for lunar craters and ridges.

Solves: Illumination Variation
Step 03

Robust Matching Engine

Cross-matching descriptors using nearest-neighbor algorithms with ratio tests, handling severe scale and rotation discrepancies.

Solves: Scale & Viewpoint Variation
Step 04

Outlier Rejection

Employing advanced RANSAC (Random Sample Consensus) or MAGSAC to rigorously filter out false-positive correspondence points and compute the fundamental geometric matrix.

Step 05

Sub-Pixel Geometric Warping

Applying the computed homography/polynomial transformation matrix to warp the source image onto the reference coordinate system at sub-pixel resolution.

Step 06

Evaluation & Metrics Extraction

Final computation of uniform point distribution, RMSE calculation, inlier ratio, and generation of the final registered image product.
